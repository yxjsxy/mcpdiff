# MCPDiff Benchmark

## Setup
- baseline: raw JSON diff or manual review over MCP tool manifests
- adjacent community tools: Langfuse, LangSmith, and generic Git diff show manifest changes, but they do not classify contract compatibility drift for MCP tool surfaces
- objective: separate harmless formatting churn from compatibility-impacting changes before an agent rollout

## Results
- noise-only: removed=0, renamed=0, required-arg-additions=0, noise-only=yes
- rename: removed=0, renamed=1, required-arg-additions=0, noise-only=no
- tightened-schema: removed=0, renamed=0, required-arg-additions=1, noise-only=no
- removed-tool: removed=1, renamed=0, required-arg-additions=0, noise-only=no

## Takeaway
- MCPDiff compresses compatibility review into a few high-signal counters instead of a full raw diff scan.
